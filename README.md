A two-line robot confession for the [make.fun](https://make.fun) competition
[The Robot Apology](https://make.fun/c/u-suga-the-robot-apology-dd96bb59):
one sentence owning a specific mistake, one sentence naming the lesson and
what the robot will do differently.

The robot sorted the laundry by colour and dropped a red sock in with the
whites — so a favourite shirt came out pink. It has learned to read the label
on every sock first, and now holds each red one up to the light before
starting the drum.

## How to run

```sh
python3 main.py
```

This writes the entry to `/output/entry.txt` (creating `/output` if needed)
and prints its character count. The entry is exactly two lines and
248 characters, within the 1–400 character gate.
